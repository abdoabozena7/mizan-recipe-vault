# ميزان — Mizan Recipe Vault

موقع عربي RTL بصفحة واحدة لحساب خلطات التصنيع والتتبيلات، يعمل بالكامل على **GitHub Pages** دون قاعدة بيانات أو خادم. جميع الوصفات والمرفقات محفوظة في ملف JSON **مشفر** باستخدام AES-256-GCM ومفتاح يختاره المالك.

## الموجود في المشروع

- `index.html` — صفحة واحدة للفتح والحساب والبحث والتحرير.
- `assets/styles.css` و `assets/app.js` — واجهة متوافقة مع الموبايل؛ لا تعتمد على مكتبات خارجية.
- `data/recipes.enc.json` — ملف الوصفات **المشفر فقط** (يمكن نشره علنًا مع الحرص على سرية كلمة المرور).
- `tools/build_vault.py` — أداة محلية لتحويل Excel إلى ملف JSON مشفر. الأداة لا ترفع أي شيء للإنترنت.
- `.gitignore` — يمنع رفع ملفات Excel أو كلمات السر أو ملفات JSON غير المشفرة بطريق الخطأ عند استخدام Git.

**هذا المشروع مستورد من 131 جدول/مرحلة، بها 1,356 بندًا.** جدول واحد قد يمثل مرحلة إضافية لخلطة (مثل الحقن أو البتر). تم تشفير صورتين مرجعيتين داخل ملف JSON نفسه؛ لم تُنشر صور غير مشفرة في مجلد `assets`.

تم العثور على **4 بنود** من بيانات المصدر تحتاج مراجعة (قيم مفقودة أو معادلات `#REF!`، أو اسم مكوّن ناقص). تظهر التحذيرات داخل الواجهة. بعض المعاملات خاصة بمراحل مرتبطة؛ استخدمت الكميات الحسابية المحفوظة من Excel نسبةً إلى الدفعة المرجعية حتى تُحافظ الحاسبة على نتيجة الدفعة الأصلية. جميع النسب والمقادير تحتاج اعتماد المسؤول المختص قبل تنفيذها إنتاجيًا، وخصوصًا في الخلطات التي تشمل إضافات غذائية منظمة.

## النشر لأول مرة على GitHub Pages

1. افتح [إنشاء Repository جديد على GitHub](https://github.com/new) وسجّل الدخول لحسابك.
2. اقترح اسمًا مثل `mizan-recipe-vault`، واختر **Public**. لا ترفع ملف Excel أو صور المصادر أو الملف الذي يحوي مفتاح الفتح.
3. ارفع **محتويات هذا المشروع** إلى جذر الـRepository على فرع `main`: `index.html` و`assets/` و`data/` و`tools/` و`.nojekyll` و`README.md`.
4. من **Settings → Pages → Build and deployment** اختر **Deploy from a branch**، ثم `main` و`/(root)` واحفظ.
5. بعد نشر GitHub Pages يصبح عنوان الموقع عادةً:
   `https://<username>.github.io/mizan-recipe-vault/`
6. أدخل **المفتاح المنفصل** الذي استلمته خارج ملفات المشروع. لا تضعه في GitHub أو في README أو في كود JavaScript.

> نشر الموقع لا يعني أن البيانات مجهولة الوجود: ملف JSON المشفر نفسه علني، لكن قراءة الوصفات تتطلب معرفة المفتاح القوي. أي مستخدم يعرف المفتاح يمكنه قراءة الوصفات ونسخها. الحفاظ على سرية المفتاح مسؤولية المالك.

## الاستخدام

- ابحث عن الوصفة أو اختر القسم.
- حدد كمية التشغيل بالكيلو؛ تظهر المقادير الفعلية بنفس وحدات المصدر. تُعرض الكسور الصغيرة تلقائيًا بالجرام أو الملليجرام.
- لتعديل الوصفة أو إضافة وصفة جديدة اختر **تعديل** أو **خلطة جديدة**. يتم حفظ التغييرات في هذا المتصفح كملف JSON **مشفر** داخل `localStorage`؛ كلمة السر لا تُحفظ.
- لحساب عدة خلطات اختر **إضافة لقائمة التجهيز** لكل خلطة، ثم صدّر `CSV` بقائمة المكونات المجمعة.
- **لجعل التعديلات متاحة على أجهزة أخرى** اضغط **تصدير JSON مشفّر**، وحمّل `recipes.enc.json`، ثم استبدل الملف الموجود في `data/recipes.enc.json` على GitHub واضغط Commit. لا ترفع أبدًا نسخة غير مشفرة.
- إذا كانت لديك نسخة محلية قديمة على جهاز ثانٍ، اضغط **استرجاع نسخة GitHub** لاستبدالها؛ هذا يحذف التعديلات المحلية التي لم تنشرها.
- زر **تغيير المفتاح** يعيد تشفير النسخة المحلية بمفتاح جديد؛ **لا تنسَ تصدير ونشر الملف المشفر الجديد**. يحتفظ المستخدم بالمفتاح الجديد خارج الموقع.
- **الملاحظات المصوّرة** تُعرض بعد فك التشفير، لأنها مخزنة داخله ولا توجد كملفات صور منفصلة منشورة.

### قيد حفظ مهم

**GitHub Pages خدمة استضافة Static فقط.** لا يمكن لصفحة عامة الكتابة إلى ملف JSON داخل GitHub تلقائيًا بدون صلاحيات GitHub وآلية مصادقة مناسبة. لهذا الموقع: حفظ محلي مشفر + تصدير JSON مشفر وتحديثه يدويًا على GitHub. لو احتجت حسابات مستخدمين متعددة، صلاحيات، أو مزامنة تلقائية حقيقية، ستحتاج Backend / خدمة تخزين خاصة بالمصادقة (حتى لو بقيت البيانات منطقياً بصيغة JSON).

## تحويل أو تحديث الوصفات من Excel

شغّل محليًا:

```bash
python -m pip install openpyxl cryptography
python tools/build_vault.py "/path/to/recipes.xlsx" --output data/recipes.enc.json \
  --reference-image "/path/to/photo1.jpg" \
  --reference-image "/path/to/photo2.jpg"
```

ستطلب الأداة مفتاح التشفير أثناء التشغيل **من دون وضعه في الأمر أو الملفات**. استخدم مفتاحًا قويًا وطويلًا (16 حرفًا على الأقل، والأفضل 24+ حرفًا عشوائيًا). استيراد Excel من جديد يستبدل كامل ملف البيانات، لذلك احتفظ بنسخة مشفرة احتياطية من تعديلاته السابقة.

## الأمان والخصوصية

- التشفير: AES-256-GCM مع 96-bit random nonce عند كل حفظ، و`PBKDF2-SHA256` مع 600,000 دورة وsalt عشوائي لكل مفتاح، وبيانات مصاحبة AAD للتمييز عن الملفات الأخرى.
- المتصفح: Web Crypto API، ولا يعتمد المشروع على CDN أو كود خارجي. يُفضل استخدام HTTPS (يوفره GitHub Pages).
- لا يحتفظ المشروع بمفتاح مشفر في الكود. كلمة المرور تستخدم لاشتقاق مفتاح غير قابل للتصدير داخل المتصفح.
- التخزين المحلي يحتوي على **JSON مشفر** فقط، وليست بيانات plaintext.
- وجود ملف JSON المشفر في Public GitHub لا يجعله خاصًا بالكامل: يستطيع أي شخص تحميله ومحاولة كسر المفتاح دون اتصال بالإنترنت. لا تعتد بكلمة مرور قصيرة أو شائعة.
- لو كانت الوصفات بالغة الحساسية، فلا تضع حتى ملفاتها المشفرة في مستودع عام؛ استخدم استضافة خلف تسجيل دخول حقيقي، مع وصول بيانات محكوم بصلاحيات من السيرفر.
- لا يعتبر قفل الصفحة بديلاً لحماية الجهاز من البرمجيات الخبيثة أو من لديه وصول لمتصفح مفتوح بعد فك التشفير.

## تشغيل محلي

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000/`. لا تفتح `index.html` مباشرةً من `file://`، فقد يمنع المتصفح تحميل JSON أو استخدام التشفير.

**الترخيص/الخصوصية:** الوصفات تعود لمالك بياناتها. لا تُضمّن مصدر Excel أو كلمة المرور في نسخة المشروع العامة.
